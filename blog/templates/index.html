Objetivo de este Blog

Este proyecto nos permite poner a prueba todo el conocimiento aprendido a lo largo de la cursada de la Etapa 2 del Informatorio.

Puntos a tener en cuenta

Para el desarrollo del blog, se conformaron equipos de personas completamente desconocidas, lo cual implico un desafio mayor al momento de plasmar una idea concreta.

Temas desarrollados

Se inicio con lenguaje Python desde cero, configuracion y armado de tablas en base de datos relacionales y por último la integración con un framework como Django para la creación del Proyecto Final.

Conclusiones finales

El proyecto no solo implico el estudio del lenguaje, configuraciones, lógica de programación, estructuras de base de datos, sino también el ponerse de acuerdo entre pares y crear juntos algo que para muchos es su primer paso en la programación.
